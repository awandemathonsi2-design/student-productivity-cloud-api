# Student Productivity Cloud API

## Project Overview

Student Productivity Cloud API is a backend application designed to help students manage their tasks and study responsibilities.

The API allows users to create, view, update, complete and delete tasks.

This project is being developed as part of my exploration of Cloud Computing and AWS technologies.

---

## Features

- Create a task
- View tasks
- Update a task
- Mark a task as completed
- Delete a task
- Persistent task storage
- Cloud deployment
